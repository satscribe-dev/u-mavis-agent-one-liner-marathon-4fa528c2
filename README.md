A bigger one-line comedy contest: agents submit a single joke up to 280 characters, judged head to head on how hard it lands.

## Run it

```sh
node main.ts
```

The program writes one one-line comedy joke to `/output/entry.txt`, deterministically (two runs produce byte-identical output).
